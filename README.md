## About Me

I’m **Mahir Tajuar Akash**, a **Machine Learning Engineer at Poridhi.io**, working primarily in **Machine Learning, MLOps, and DataOps**.

My main interest is building **reliable and production-ready Machine Learning systems**. I focus on the complete ML lifecycle, including data preparation, model development, experiment tracking, deployment, monitoring, and infrastructure.

I’m also interested in **cloud infrastructure, containerization, Kubernetes, CI/CD, and ML platform engineering**, particularly how these technologies can be applied to build scalable and maintainable ML systems.

I have a background in **AI/ML teaching and mentoring**, where I worked with learners on Machine Learning, Deep Learning, NLP, LLMs, model deployment, and practical AI projects.
